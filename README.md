# 한국어 교부 문헌 원자료

[정식 읽기 사이트](https://patristics.missionalbible.org/) · [미셔널 바이블](https://www.missionalbible.org/)

이 저장소는 한국어 교부 문헌의 고정판 원자료를 보존합니다. 새 공개 화면은 [missionalbible-patristics](https://github.com/imtseoul/missionalbible-patristics)에 배포합니다.

`releases/`의 원문·한국어 번역·판본·인용·검토 기록과 체크섬은 공개 당시의 파일입니다. 무료로 제공하며, 자료별 출처와 재사용 조건은 [이용 조건](https://patristics.missionalbible.org/rights.html)과 각 JSON의 `rights`를 확인해 주세요.

한국어 번역과 단어·구 대응은 AI 작업이며 사람 검수 여부와 실제 검사 범위를 구절별로 기록합니다. `source.text`는 사용한 대본이고 `upstream_text`는 교정 전 입력입니다. 인용할 때 `citation`과 `review_state`, 원문과 번역의 수정본 ID를 함께 확인해 주세요.

새 사이트가 분리한 과거 대용량 파일은 이 저장소의 특정 Git 수정본에서 제공합니다. 고정 인용에는 해당 수정본의 URL을 사용합니다. 최신 수록 목록과 읽기 주소는 [정식 목록](https://patristics.missionalbible.org/catalog.json)에서 확인할 수 있습니다.
