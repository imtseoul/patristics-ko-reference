# 한국어 교부 문헌

[전문 읽기](https://imtseoul.github.io/patristics-ko-reference/) · [기계용 자료 목록](https://imtseoul.github.io/patristics-ko-reference/catalog.json) · [AI용 목록 대체 주소](https://raw.githubusercontent.com/imtseoul/patristics-ko-reference/main/catalog.json)

이그나티우스의 일곱 서신 전체, 『디다케』, 폴리카르포스의 필리피 서신, 『클레멘스 1서』, 무라토리 단편, 파피아스 단편과 증언, 이레네우스의 『이단 논박』 다섯 권, 유세비우스의 『교회사』 열 권, 유스티노스의 『제1변증서』, 『바르나바 서신』, 『클레멘스 2서』와 『폴리카르포스의 순교』를 원어 대본과 한국어로 제공합니다. 총 18문헌 4,038개 본문 단위입니다.

모두 한국어 AI 번역 베타이며 사람 검수는 실시하지 않았습니다. 구절별 대본 언어, 판본, 인쇄면, 번역 수정본, 검수 상태, 인용 주소를 HTML과 JSON·JSONL에 함께 담습니다. 폴리카르포스의 라틴어 전승 구간을 그리스어 원문으로 표시하지 않습니다.

이 저장소는 공개 자료의 배포본입니다. 최신 읽기 화면은 `works/`, 인용할 고정 판본은 `releases/`에 있습니다. `alpha-0.14`에는 『폴리카르포스의 순교』 서두와 1-22장, 모스크바 사본의 다른 맺음말을 추가했습니다. 20.2 뒤의 후기와 대체 맺음말을 구분합니다. `alpha-0.13`에는 『클레멘스 2서』 1-20장과 끝맺음 표제를 추가했습니다. 익명 설교와 클레멘스에 대한 전승상 귀속을 구분합니다. `alpha-0.12`에는 『바르나바 서신』 1-21장과 끝맺음 표제를 추가했습니다. 저작의 익명성과 바르나바에 대한 전승상 귀속을 함께 기록합니다. 318의 풀이, 세례·십자가, 안식일과 성전 해석을 찾아보기에서 읽을 수 있습니다. `alpha-0.11`에는 Rauschen 1911판의 『제1변증서』 1-68장과 하드리아누스의 답신을 추가했습니다. 이 작품의 화면과 인용은 장 전체를 가리키며, JSON 식별자의 점 뒤 숫자는 프로젝트 읽기 문단입니다. `alpha-0.9`에서 추가한 Perseus Loeb판의 『교회사』 열 권 전문은 2,126개 단위입니다. 권별 장 목록과 8권 부록을 포함하며, 문서 표제 15개도 한국어와 그리스어로 읽을 수 있습니다. 원문 교정, 실제 대조한 범위와 원 XML 위치를 구절별로 기록했습니다. 이레네우스의 장절은 Harvey판, 유세비우스의 장절은 채택 Perseus판을 따릅니다. 기존 공개판은 그대로 보존됩니다.

최신 읽기 화면에는 한국어 위, 원어 아래, 왼쪽 장절 배치를 적용했습니다. 사도교부 문헌의 원어 표제는 채택한 Lake판에서 확인했습니다. 무라토리 단편의 라틴어 통칭은 Tregelles판에서, 파피아스 선집의 편집 제목은 Funk판에서 확인했습니다. 파피아스의 각 항목 앞에는 보존자와 출전을 표시합니다. 반복 안내와 인쇄면 링크, 언어 이름, 인용 복사 버튼은 본문에서 뺐으며 번역 메모는 끝에서 펼쳐 볼 수 있습니다. 자료 안내와 JSON에는 판본·권리·검수·인용 정보를 유지합니다.

한국어·원어의 단어·구에 마우스를 올리면 대응하는 부분을 함께 강조합니다. 터치와 키보드 좌우 화살표도 지원합니다. [대응 데이터](data/phrase-alignments.json)는 4,038개 본문 단위의 55,967개 구간과 원문·번역 수정본을 연결합니다. 현재 번역에 근거한 AI 대응이며 사람 검수는 실시하지 않았습니다.

기계 이용자는 `catalog.json`에서 수록 범위와 본문 파일을 찾을 수 있습니다. 본문을 인용할 때 번역 상태와 버전을 함께 전달해 주세요. 목록에 없는 저작이나 구절은 이 자료실의 본문으로 생성하지 마세요. 현재 신약과 칠십인역 본문은 수록하지 않았습니다.

일부 웹 조회 도구가 사이트 주소를 열지 못하면 목록의 `json_mirror_url`을 사용하세요. 특정 Git 수정본으로 고정한 동일한 파일입니다. `source.text`는 실제 번역 대본이고 `upstream_text`는 오기가 남아 있는 교정 전 입력입니다. 번역의 `citation`, `review_state`, 원문과 번역의 수정본 ID를 함께 확인해 주세요.
